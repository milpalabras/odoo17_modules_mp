# Módulo de Prueba - Odoo 17 ## Descripción Módulo de demostración creado por Sergio Milpalabras para testing y desarrollo en Odoo 17. ## Características - ✅ Modelo personalizado con campos variados - ✅ Vistas de lista, formulario y búsqueda - ✅ Sistema de etiquetas con colores - ✅ Barra de progreso - ✅ Botones de acción - ✅ Datos de demostración - ✅ Menús organizados - ✅ Permisos de seguridad ## Instalación 1. Copia el módulo a tu carpeta de addons 2. Actualiza la lista de aplicaciones 3. Instala "Módulo de Prueba" ## Uso El módulo añade un nuevo menú "Módulo Prueba" donde puedes: - Crear registros de prueba - Gestionar etiquetas - Probar funcionalidades básicas ## Autor Sergio Milpalabras sergio.milpalabras@gmail.com
