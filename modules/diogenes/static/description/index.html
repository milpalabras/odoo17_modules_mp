Diógenes - Finanzas Personales

Aplicación que te ayuda a mantener un registro completo de gastos e ingresos para alcanzar la libertad financiera.

Características Principales

📊 Seguimiento de Gastos e Ingresos

Registra y categoriza fácilmente tus transacciones financieras para tener una visión clara y completa de tu situación económica.

  • Registro rápido de transacciones
  • Categorización personalizable
  • Seguimiento en tiempo real
  • Historial completo de movimientos

💰 Presupuesto Personalizado

Establece presupuestos mensuales basados en tus metas financieras y realiza un seguimiento detallado de tu progreso.

  • Presupuestos por categoría
  • Alertas de límites de gasto
  • Visualización de progreso
  • Comparativas mensuales

🎯 Planificación Financiera

Crea y visualiza planes financieros a largo plazo para alcanzar tus objetivos.

  • Metas de ahorro
  • Planificación de inversiones
  • Objetivos de jubilación
  • Seguimiento de progreso hacia metas

Módulos Incluidos

📝 Transacciones

Para qué sirve: Registrar cada movimiento de dinero que haces.

Uso práctico:

  • Registras "Compra en supermercado - $50" como GASTO → Categoría: Alimentación
  • Registras "Pago de salario - $2000" como INGRESO → Categoría: Salario
  • Puedes confirmar transacciones (para separarlas de borradores)
  • Cancelar si fue un error y ver historial completo

Es como llevar una libreta donde anotas cada compra y cada ingreso que recibes.

🏷️ Categorías

Para qué sirve: Organizar tus transacciones en grupos lógicos.

Uso práctico:

  • Categorías de GASTOS: Alimentación, Transporte, Vivienda, Servicios...
  • Categorías de INGRESOS: Salario, Freelance, Inversiones...
  • Puedes crear nuevas: "Mascotas", "Gimnasio", "Suscripciones"
  • Cada categoría tiene color para identificarla rápido

Como tener cajones en un mueble - cada cajón guarda un tipo de gasto específico.

💵 Presupuestos

Para qué sirve: Establecer límites de gasto por categoría cada mes.

Uso práctico:

  • Creas: "Presupuesto Alimentación Enero: $300"
  • El sistema suma automáticamente todos tus gastos de Alimentación en enero
  • Te muestra: Gastado $250 / Presupuestado $300 = 83% usado
  • Si te pasas (100%+), te lo marca en rojo como alerta

Es como decir "este mes solo puedo gastar $100 en restaurantes" y la app te avisa cuando estás cerca del límite.

🎯 Metas Financieras

Para qué sirve: Definir objetivos financieros a largo plazo y seguir tu progreso.

Uso práctico:

  • Creas meta: "Ahorrar para vacaciones - $5,000 - Fecha límite: Diciembre"
  • Vas actualizando: "Ya tengo $2,500 ahorrados"
  • El sistema calcula automáticamente: 50% completado
  • Puedes tener múltiples metas: jubilación, casa, carro, emergencias

Como una alcancía con objetivo - defines cuánto quieres juntar y para cuándo.

¿Cómo trabajan juntos?

  1. Registras transacciones diarias (gastos e ingresos)
  2. Las categorías las organizan automáticamente
  3. Los presupuestos te alertan si gastas de más en alguna categoría
  4. Las metas te motivan a ahorrar para objetivos específicos
